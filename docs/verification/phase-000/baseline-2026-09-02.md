## Economy ownership and call graph

CodeGraph identified the economy boundary and its blast radius. `BalanceManager` owns the process-wide provider reference, initializes `InternalEconomyProvider` on `ServerStartingEvent`, clears it on `ServerStoppingEvent`, and rejects access before initialization. `InternalEconomyProvider` owns balance reads and checked deposit, withdrawal, transfer, and leaderboard operations. It persists balances through overworld `InternalBalanceSavedData`, whose schema is version 1. `EconomyProvider` is the current interface for balance, deposit, withdrawal, transfer, leaderboard, currency name, and decimal places. `TransactionResult` carries operation outcomes.

## Preliminary Pixelmon API observations

The official Pixelmon 9.4.0 API reference identifies the economy package as `Pixelmon 9.4.0-PIPE30856 API`. The documented `BankAccount` interface exposes a UUID identifier, `BigDecimal` balance reads, balance checks, and `BigDecimal` `add` and `take` mutations. `BankAccountManager` and `BankAccountProxy` expose asynchronous and immediate account lookup by UUID, and `PixelmonInitEvent` exposes the account manager during Pixelmon initialization. The documented `EconomyEvent.PreTransaction` is cancellable before an account mutation and supplies the transaction type, prior balance, and requested change. `EconomyEvent.PostTransaction` is emitted after the mutation and supplies old and new balances.

These pages establish a possible query and preflight integration surface, but they do not prove the phase contract. The documented mutation methods return only a boolean and accept no FutureShops request UUID or durable receipt lookup. The documented events likewise expose balance values and transaction type, not a stable operation identity. Exact artifact bytes, implementation behavior, and any bridge supplied idempotency or outcome lookup remain unverified, so `EXT-001` and `EXT-003` remain blocked. Sources: [BankAccount](https://reforged.gg/docs/1211/com/pixelmonmod/pixelmon/api/economy/BankAccount.html), [BankAccountManager](https://reforged.gg/docs/1211/com/pixelmonmod/pixelmon/api/economy/BankAccountManager.html), [BankAccountProxy](https://reforged.gg/docs/1211/com/pixelmonmod/pixelmon/api/economy/BankAccountProxy.html), [PixelmonInitEvent](https://reforged.gg/docs/1211/com/pixelmonmod/pixelmon/api/events/init/PixelmonInitEvent.html), [EconomyEvent.PreTransaction](https://reforged.gg/docs/1211/com/pixelmonmod/pixelmon/api/economy/EconomyEvent.PreTransaction.html), and [EconomyEvent.PostTransaction](https://reforged.gg/docs/1211/com/pixelmonmod/pixelmon/api/economy/EconomyEvent.PostTransaction.html).
