# Phase 004 security and command audit

This packet records the NeoForge 1.21.1 audit for the phase 004 security and command boundary.

## Scope

The audit covers serverbound payload decoders, paged history and leaderboard requests, shop catalog and admin catalog filesystem access, promotion values, command argument bounds, persistent paging arithmetic, and the client server trust boundary.

The NeoForge line does not contain the Forge market claim collection packet. Issue 44 is therefore Forge only.

## Findings and repairs

* Issue 40 is addressed by bounded catalog enumeration, bounded UTF 8 reads, regular file checks, and rejection of symlinked `futureshops` and `shops` directories.
* Issue 41 is addressed by explicit maximum lengths on every serverbound text decoder.
* Issue 42 is addressed by shared page bounds, bounded `/baltop` arguments, and early return before sorting when the requested offset is outside the available balance set.
* Issue 43 is addressed by validating paged payloads and using long offset arithmetic before narrowing to a list index.
* Issue 45 is addressed by finite and domain bounded promotion values, including the buy X get Y path.
