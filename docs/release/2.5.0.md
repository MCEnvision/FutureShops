# FutureShops 2.5.0

Minecraft 1.21.1, NeoForge 21.1.248, Java 21, and GeckoLib 4.8.4. EnVy personally verified 2.5.0 and approved its merge on 2026-09-25.

## Fixed

* Admin shop purchases and cart checkout now charge the dynamically adjusted price.
* Admin shop sales now pay the adjusted sell price, preserving the configured buy and sell relationship subject to minor unit rounding.
* Shop catalogs and cart verification now use adjusted prices, and open shop sessions refresh when a recalculation changes prices.
* Confirmation dialogs retain their displayed price revision, so an outdated confirmation is rejected before money or items move.

Buy promotions apply after the dynamic adjustment. Sell only listings are supported. Player owned shop pricing and external economy integrations are otherwise unchanged. The existing demand, supply, and decay formula is preserved.

Install the identical jar on client and server. Back up the complete world and configuration before upgrading. Existing pricing history is retained and can affect the first quote after upgrade. No new configuration flag or saved data migration is required.

See [pricing behavior and diagnostics](../features/dynamic-pricing.md) and the [required local test procedure](../test/dynamic-pricing-2.5.0.md).
